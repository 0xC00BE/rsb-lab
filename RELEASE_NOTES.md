# RSB Brewery ICS Lab v1.0.0

First public release of a segmented brewery cybersecurity training lab.

- Six OpenPLC process cells with Modbus TCP, BACnet/IP and DNP3.
- Dashboard-P1 through P4, all FUXA artwork, Scada-LTS project exports,
  a historian, Grafana and Node-RED flows.
- Windows domain and workstation role installers with supporting service source.
- VMware provisioning, isolated networking and optional admin/student VPN.
- Installation guides, a student brief and optional instructor material.

Start with [README.md](README.md). See [tested platforms and limits](docs/support.md)
for the supported reference setup. Original project material and authorized
artwork use MIT; OS media/licensing and infrastructure are operator supplied.
The source ZIP and SHA-256 checksum exclude private state, credentials and VM disks.
