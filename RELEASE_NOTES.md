# RSB Brewery ICS Lab v0.1.1

This update replaces the older FUXA visual project with the four current
production dashboards: **Dashboard-P1, Dashboard-P2, Dashboard-P3 and
Dashboard-P4**. All 26 current PNG assets are included. The gallery shows these
four screens, and the repository uses the same brewery logo as FUXA.

Fresh installations import only these dashboards. Existing release installations
can use the [backed-up FUXA upgrade](projects/fuxa/README.md#upgrade-an-existing-release-installation)
to remove known legacy views while preserving editor credentials. A stale start
page and the P4 navigation spelling are corrected in the release copy.

The VMware lab, optional admin/student VPN and other services continue from
v0.1.0. See [VALIDATION.md](VALIDATION.md) for the original independent build and
the separate dashboard update checks. The Jump-host escalation path remains
untested at the owner’s request. Proxmox deployment is not validated.

Original source and the authorized artwork are MIT licensed. Supply your own
OS media/licensing and infrastructure. Private credentials, VPN identities,
VM disks and database backups are excluded. Earlier releases remain unchanged.
